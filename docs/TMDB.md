# Фильмы и сериалы: TMDB

Статус: исходный код и офлайн-тесты в репозитории. TMDB-токен пользователя пока **не настроен**, реальная сеть и Telegram Mini App не тестировались. TMDB предоставляет **метаданные**, не потоковые фильмы.

## Подключение

Завести отдельный TMDB API Read Access Token в личном аккаунте TMDB (Settings → API), сохранить **только** в локальном `.env` сервера:

```env
TMDB_READ_TOKEN=
```

Пока переменная пуста, поиск TMDB выключен, секция Mini App скрыта. Бот/чат сообщает о необходимости настройки. Никакие токены никогда не коммитить в GitHub и не передавать браузеру. API использует header `Authorization: Bearer ...`, а не токен в URL. Официально: https://developer.themoviedb.org/docs/authentication-application

## Работа

- `/film Интерстеллар` — поиск фильмов и обычных сериалов, только метаданные TMDB.
- `/films` — личные отметки в SQLite.
- `/filmstatus movie 157336 done` — пример статуса.
- `/filmprogress TV_ID 2 5` — сериал, сезон 2, серия 5 (после добавления в watchlist).
- `/filmrate movie 157336 9` — личная оценка 1–10.
- В Mini App поиск, категории фильм/сериал, статусы, оценки, прогресс сериала.

Идентичность разделяется по паре `(media_type,tmdb_id)`; каталоги не содержат видео, файлов, ссылок на просмотр или Telegram `file_id`. Контент из API не вставляется в HTML неэкранированным.

## Технические ограничения

Один фиксированный HTTPS API `https://api.themoviedb.org/3/search/multi`, `include_adult=false`, `language=ru-RU`. Авторизация read-only, таймаут, ограничение JSON до 1 МБ, запрет редиректов, общий SQLite rate-limiter между bot и web, кеш на 24 часа. Полноценной модели сезонов/эпизодов, их метаданных и календаря выхода пока нет: сохраняется только введённая позиция просмотра.

Нельзя обещать просмотр фильма только на основании записи в TMDB. Для этого нужен отдельный правомерный источник реального видеофайла и совместимость с Telegram-плеером.
