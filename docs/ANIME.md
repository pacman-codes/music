# AniList: каталог и личный список аниме

Код реализован на основе публичного GraphQL AniList; сервер ещё не развёрнут, реальный ответ AniList и воспроизведение на телефоне не проверялись.

## Поиск и личный список

В обычном Telegram-боте:
- `/anime Cowboy Bebop` — поиск по AniList.
- `/animelist` — личный список.
- `/animestatus 1 watch` — отметить «Смотрю».
- `/animeprogress 1 7` — число просмотренных серий.
- `/animerate 1 9` — оценка 1–10.

В Mini App есть секция «🎞 Аниме», поиск, выбор статуса, прогресс и оценка. Статусы: `planned`, `watching`, `completed`, `on_hold`, `dropped`. Данные хранятся в SQLite независимо от внешней учётной записи AniList. Сервис не изменяет личный AniList-профиль.

## Техническая схема

Используется фиксированный POST-запрос `https://graphql.anilist.co` с GraphQL-переменными. Для поиска `Page { media(search:...,type:ANIME,isAdult:false) }`. Возвращаются только названия (English/Romaji/native), ID AniList/MAL, год, число серий, формат, статус выхода и средняя оценка. Пользовательский GraphQL-код/URL не принимается.

Защита: owner-only Telegram ID и проверяемая подпись Mini App, HTTPS только на одном хосте, запрет редиректов, таймаут, ответ не более 1 МБ, SQLite-кеш 12 часов и 2,1 с между запросами для общей базы bot+web. Документация AniList на 14.11.2026 отмечает временный лимит **30 запросов/мин**; этот режим может измениться. При 429 сервис показывает, что запросы временно ограничены.

SQLite `anime_titles` и `anime_watchlist` — отдельные таблицы; старые музыкальные файлы и плейлисты сохраняются.

## Что НЕ сделано

- Файлы серий, потоковое видео, поиск озвучек/субтитров и Telegram-видеоплеер.
- Поиск фильмов/обычных сериалов TMDB, получение ключа и история просмотров.
- Реальный сетевой smoke-test с AniList и UI на мобильном Telegram.

Родной Telegram-плеер для музыки не изменялся. Не путать найденное аниме с доступным видео.
