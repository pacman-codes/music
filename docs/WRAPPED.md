# Music Wrapped: личная статистика

Команда `/wrapped 7d`, `/wrapped 30d`, `/wrapped 365d`, `/wrapped all` и раздел «📊 Music Wrapped» в Mini App показывают проверяемые агрегаты SQLite.

Доступные метрики: сколько аудиосообщений **отправлено** текущему Telegram-пользователю, число разных отправленных песен, исполнители по отправкам, любимые артисты, количество сохранённых и оценённых треков, средняя оценка, вручную отмеченные пропуски и дослушивания, отложенные/импортированные записи, отправки по дням за 7 дней. Доступ защищён Telegram initData и OWNER_TELEGRAM_ID, чужие лица не видят данные.

**Главное ограничение:** Bot API не знает, включил ли пользователь песню, дослушал ли её, сколько минут играл плеер или был ли реальный skip. Отправки не называются прослушиваниями; `Music Wrapped` не выдумывает часы, жанры и play count. Для точных метрик когда-либо потребуется отдельный инструментированный плеер.
