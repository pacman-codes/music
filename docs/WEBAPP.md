# Mini App: настройка и безопасность

## Включить

1. Получить отдельный BotFather-токен и указать его только в приватном .env.
2. В .env настроить OWNER_TELEGRAM_ID.
3. Запустить Telegram-бота и web API (Compose либо раздельно).
4. Настроить HTTPS reverse proxy для локального 127.0.0.1:8085 на собственном домене.
5. Прописать WEBAPP_URL=https://имя-домена в .env и перезапустить бот.
6. Открыть /start и нажать кнопку «📱 Открыть медиатеку». Протестировать отправку подборки в чат.
7. До запуска в production обязательно проверить реальный iOS/Android UX и восстановление базы.

**Не использовать домены, контейнеры или базу Soodoo**, пока миграция VPN не завершена. Проект music запускается отдельно.

## Авторизация

Browser Telegram.WebApp.initData передаётся в заголовке X-Telegram-Init-Data каждого API запроса. На сервере:
- ограничение длины 8192 байт и максимум 32 поля;
- отказ от повторяющихся полей;
- проверка HMAC-SHA-256 по bot token и правилу WebAppData;
- timestamp не старше 3600 секунд, не дальше 30 секунд в будущее;
- обязательный user.id, в точности равный OWNER_TELEGRAM_ID.

Ответы API не содержат file_id, токены или исходные приватные ссылки. Статические файлы могут быть видны без Telegram, но API из браузера без валидного initData закрыт.

## Оценки и ручная обратная связь

- Оценка 1–10 независима от избранного.
- Пропуски и дослушивания отмечаются только вручную; native Telegram player не отправляет эти события боту.
- API проверяет Telegram initData, а входные значения рейтинга и типа события валидируются.
- Статистика в интерфейсе — ручные отметки за последние 30 дней, максимум 20 на трек; отправленные файлы не считаются прослушанными.

## Ограничения

API /api/queue отправляет Telegram audio из уже загруженных файлов. Если бот раньше не получал аудио от владельца, отправлять нечего. Внешний поиск по музыкальным сервисам ещё не реализован. HTTPS endpoint должен быть защищён от общего публичного abuse через reverse proxy, request limits и rate limits.

История отправки отличается от фактического прослушивания. Любые тесты после смены бота требуют повторной загрузки существующих Telegram file_id.

## Новые музыкальные функции

- «✨ Для меня»: персональные находки на основе до трёх любимых исполнителей.
- «🎸 Радио» у трека: поиск новых записей по подтверждённому Artist MBID.
- «🔍 Найти запись»: MusicBrainz-предложения для файла из Telegram. Совпадение подтверждается пользователем; текстовое равенство не делает файл подтверждённым.
- У созданного через импорт Telegram-аудио связь не удаляется обычной командой `unmatch`.
- Отсутствие реального `file_id` по-прежнему означает «Пока без аудио».
