# План music

Все выполненные пункты означают реализацию **в GitHub**, не деплой на сервер или проверку на телефоне.

## v0.1 — базовая библиотека
- [x] Репозиторий music полностью заменил VOID-код в текущем main.
- [x] Личный бот, SQLite, ограничение по владельцу, Docker, тесты и GitHub Actions.
- [x] Приём аудиофайлов Telegram, хранение file_id, избранное и пользовательские плейлисты.

## v0.2 — полноценные плейлисты и подборка
- [x] Переименование/удаление плейлистов (с подтверждением).
- [x] Удаление из плейлиста и ручная перестановка треков.
- [x] Локальный поиск по сохранённым файлам.
- [x] Взвешенная локальная Волна, режим открытий, явная обратная связь.
- [x] История выданных треков и понижение частоты недавних повторов.
- [x] Очередь сохраняется в SQLite и выдаётся порциями до 10 файлов с кнопкой «Ещё 10».
- [x] Инлайн-меню Telegram и кнопки под треками.

## v0.3 — первая версия Mini App
- [x] Адаптивный веб-интерфейс: Волна, плейлисты, библиотека, поиск, лайки.
- [x] FastAPI с HMAC Telegram initData, owner-only и ограниченным временем жизни.
- [x] Кнопка Mini App в боте при заданном WEBAPP_URL.
- [x] API отправки выбранной подборки в родной плеер Telegram.
- [x] Контейнер web на локальном порту с будущим HTTPS reverse proxy.
- [ ] Проверить взаимодействие настоящего Telegram Mini App, кнопки и плеера на iPhone и Android.
- [ ] Публичный HTTPS для будущего music-домена (только после освобождения старого сервера).

## v0.4 — качественная персонализация
- [ ] MusicBrainz ID, сопоставление оригиналов, каверов и live записей.
- [ ] ListenBrainz, Last.fm: поиск похожих исполнителей и новых кандидатов.
- [ ] Настройки доли нового и знакомого, настроение и «Радио по треку».
- [ ] Удобное добавление кандидатов из разрешённых источников с проверкой формата и прав.
- [ ] Резервное копирование, мониторинг размера очередей, восстановление неотправленных медиа.

## v0.5 — фильмы и аниме
- [ ] Поиск TMDB/AniList, сезоны, серии, история.
- [ ] Подключаемые источники доступного для законного просмотра видео.
- [ ] Отправка имеющихся видеофайлов через Telegram с учётом лимитов и конвертации.
- [ ] Временный кеш под квотой, оценка ресурсов CPU/RAM/трафика.
