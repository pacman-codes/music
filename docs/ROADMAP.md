# План music

Пункты [x] отражают код в репозитории. Они не означают, что бот уже запущен на сервере.

## v0.1 — сделано
- [x] Независимый личный бот вместо старого кода VOID.
- [x] Owner-only доступ, SQLite, Docker Compose, CI и тесты.
- [x] Аудиофайлы через Telegram file_id, понравившиеся, свои плейлисты.
- [ ] Проверка на реальном Telegram-аккаунте и устройстве.

## v0.2 — музыкальная библиотека и очередь
- [x] Переименование и удаление пользовательских плейлистов (удаление с подтверждением).
- [x] Удаление песен из подборок, перестановка треков.
- [x] Кнопки Telegram: Волна, понравившиеся, плейлисты, «Ещё 10», добавить/лайк/дизлайк.
- [x] Очередь сохраняется в SQLite, отправляется порциями до 10 аудиофайлов.
- [x] История отправки и пониженный вес недавно отправленных песен.
- [x] Режим открытий из собственной библиотеки, штраф за повторы исполнителя.
- [ ] Продолжение подборки в бесконечном режиме с подбором новых кандидатов.
- [ ] MusicBrainz (сопоставление оригиналов, каверов, ремиксов), ListenBrainz/Last.fm.
- [ ] Режим радио по треку/исполнителю и персональные настроения.
- [ ] 60/30/10 по **внешним** кандидатам, не псевдооткрытия из локального каталога.
- [ ] Права на скачивание, таймауты, rate limits внешних медиаисточников.

## v0.3 — Telegram Mini App
- [ ] Responsive интерфейс, поиск, библиотека, избранное, плейлисты.
- [ ] Проверяемый сервером Telegram initData + owner-only API.
- [ ] Отправка выбранных треков в нативный плеер Telegram; не свой аудиоплеер.
- [ ] UX проверки на iPhone и Android.

## v0.4 — фильмы/аниме
- [ ] TMDB/AniList и отдельная модель сезонов/серий.
- [ ] Подключаемый поиск доступных законных источников просмотра.
- [ ] История просмотра, субтитры, озвучка, прогресс.
- [ ] Опциональный квотируемый ingest в Telegram для разрешённых файлов.
