# План music

Все выполненные пункты означают реализацию **в GitHub**, не деплой на сервер или проверку на телефоне.

## v0.1 — базовая библиотека
- [x] Репозиторий music полностью заменил VOID-код в текущем main.
- [x] Личный бот, SQLite, ограничение по владельцу, Docker, тесты и GitHub Actions.
- [x] Приём аудиофайлов Telegram, хранение file_id, избранное и пользовательские плейлисты.
- [x] `/play ID`, быстрые кнопки под результатами поиска и в библиотеке, одиночный Telegram sendAudio из Mini App с контролами оценки.
- [x] При ошибке отправки одиночного Telegram file_id выдаётся понятная ошибка, а не фиктивное «прослушано» или продвижение очереди.

## v0.2 — полноценные плейлисты и подборка
- [x] Переименование/удаление плейлистов (с подтверждением).
- [x] Удаление из плейлиста и ручная перестановка треков.
- [x] Локальный поиск по сохранённым файлам.
- [x] Взвешенная локальная Волна, режим открытий, явная обратная связь.
- [x] Оценки 1–10, отдельно от «Мне нравится».
- [x] Ручные события «Пропустил» / «Дослушал» в боте и Mini App.
- [x] Снижение веса песен при частых пропусках и бонус за дослушивания; усталость от трека не удаляет его из избранного.
- [x] Регрессионные тесты старой базы, подписанной авторизации, поведенческой статистики.
- [x] Неактивный прототип HTML-виджета оценок с безопасным escaping.
- [ ] Интеграция widget_query после снятия запрета для обычных production-ботов (Telegram issue #947), поддержки aiogram и проверки клиентов.
- [x] История выданных треков и понижение частоты недавних повторов.
- [x] Очередь сохраняется в SQLite, выдаётся порциями до 10 файлов с кнопкой «Ещё 10».
- [x] Каждая «Ещё 10» привязана к cursor очереди: повторный клик или старая карточка не отправляет следующую порцию.
- [x] «Волна» и «Открытия» пересчитывают каждую следующую порцию по актуальным оценкам/отметкам, а не по устаревшему snapshot.
- [x] Сохранение привязок будущих HTML-виджетов к сообщениям, проверка владельца и защита запросов от повторного применения (пока без отправки самих виджетов).
- [x] Инлайн-меню Telegram и кнопки под треками.
- [x] Инлайн-панель оценки всех треков сразу после порции аудио, без HTML-виджетов.

## v0.3 — первая версия Mini App

- [ ] Публичный HTTPS для будущего music-домена (только после освобождения старого сервера).

## v0.4 — качественная персонализация
- [x] Поиск MusicBrainz по записам и нормализация metadata, грубый фильтр live/remix/cover, дедупликация по артисту и названию.
- [x] ListenBrainz: радио по исполнителю (easy/medium/hard) с преобразованием MBID в названия треков через MusicBrainz.
- [x] Строго ограниченные HTTP-запросы, 1.1 с между запросами MusicBrainz, кеш SQLite.
- [x] Mini App: глобальный поиск, карточки кандидатов, список «Отложено».
- [x] Поиск MusicBrainz и радио ListenBrainz прямо в Telegram-боте без опубликованного Mini App (`/find`, `/radio`, `/saved`).
- [x] API сохраняет кандидата в отложенное только после поиска в авторизованной сессии.
- [x] API поиска внешних метаданных не подсовывает записи в Telegram как уже доступные треки.
- [x] Опциональный импорт прямых MP3/M4A из allowlist HTTPS-хостов в `sendAudio`.
- [x] 45 МБ лимит, 90 с таймаут, отсутствие редиректов, автоудаление временного файла.
- [x] После подтверждения Telegram запись MBID привязывается к реальному `file_id`, повторный импорт не качает файл.
- [x] Импорт защищён owner-only Mini App API, по умолчанию отключён без переменной `MUSIC_ALLOWED_MEDIA_HOSTS`.
- [x] Команда `/import MBID URL` в Telegram-боте для загрузки из разрешённого источника без Mini App HTTPS.
- [x] Тесты безопасности URL, ошибок HTTP и очистки временного файла без живой сети.
- [x] Опциональный yt-dlp поиск роликов YouTube без ключа API, проверка ID, лимит 8 результатов.
- [x] MusicBrainz → несколько вероятных YouTube-версий, ранжирование по названию/исполнителю/длительности, штраф за live/remix.
- [x] Предложения доступны через `/ytfor MBID` и кнопку в Mini App; пользователь вручную выбирает конкретную запись.
- [x] Опциональный /ytget и Mini App импорт одного YouTube-ролика как MP3 в нативный Telegram sendAudio.
- [x] Конвертация FFmpeg, ограничение 20 минут, 45 МБ итогового файла и 80 МБ временного диска, таймаут.
- [x] Флаги в .env и отдельная сборка Docker с yt-dlp+FFmpeg, по умолчанию отключено.
- [x] Метаданные видео и Telegram file_id хранятся отдельно с защитой от повторного скачивания.
- [x] SQLite leases предотвращают одновременный импорт одного видео/MP3 между bot и web; ошибки очищают lease, аварийная блокировка истекает.
- [x] Сквозные офлайн-тесты поиска YouTube, загрузки в нативное аудио Telegram, сохранения file_id, повторной отправки и добавления в Волну.
- [x] Явное подтверждение MusicBrainz MBID при выборе видео, сохранение корректных артистов/названий вместо названия YouTube-канала и связь с каталогом.
- [x] Глобальная SQLite capacity lease на bot + web: максимум один активный импорт с временной защитой от одновременной конвертации.
- [x] Docker tmpfs /tmp до 128 MiB на контейнер, чтобы временные файлы не занимали постоянный диск.
- [x] Офлайн-тесты парсинга YouTube, запрета произвольных URL и owner-only API.
- [ ] Проверка реальной доступности YouTube-извлечения на сервере; PO Token, cookie/DRM-обход не внедрены.
- [ ] Автоматическое сопоставление записей MusicBrainz с разрешёнными аудиоматериалами, включая качество, оригинал/ремикс.
- [ ] Переключаемый поиск источников с учётом условий сервиса и прав на скачивание.
- [x] Ручное подтверждение MusicBrainz MBID для уже загруженных треков; импортированные ссылки защищены от случайной ручной перезаписи.
- [x] Похожие названия без подтверждения не помечаются как уже найденный файл.
- [x] «Радио по треку» с подтверждённым Artist MBID или запасным поиском по исполнителю; фильтрация уже загруженных записей.
- [x] Доступно в Mini App и чат-командах `/identify`, `/unmatch`, `/radiotrack`.
- [x] «Для меня» — до трёх исполнителей из оценки 7–10 и избранного, с учётом частых ручных пропусков; исключение дублей, равномерное перемешивание результатов.
- [x] Личный каталог в Mini App и команда `/recommend` без Mini App.
- [ ] Истинное персональное радио на уровне музыкальных предпочтений/жанров с feedback-loop и тестами на реальных рекомендациях.
- [ ] Last.fm как дополнительный источник сигналов, жанровые и контекстные рекомендации.
- [ ] Смешивание доступных новых файлов с локальной «Волной» после импорта в Telegram и оценки качества.
- [ ] Настройки доли нового и знакомого, настроение и режим «Радио по треку» **с нативным воспроизведением только реально доступных аудиофайлов**.
- [ ] Удобное добавление кандидатов из разрешённых источников с проверкой формата и прав.
- [x] CLI для согласованного резервного копирования SQLite + тест восстановления содержимого.
- [x] CLI для ручной безопасной очистки устаревших кешей, очередей, виджетов и истории с dry-run по умолчанию.
- [ ] Периодический off-host backup, мониторинг размера очередей, восстановление неотправленных медиа.
