# Еженедельные музыкальные находки

`/weekly` и кнопка «📅 Неделя» в Mini App обращаются к публичному ListenBrainz fresh-release API и к персональному радио по любимым артистам. Показываются релизы за последние **14 дней** и новые кандидаты. Релиз имеет release-group MBID, а не recording MBID: релиз **не добавляется автоматически** в список аудиотреков, даже если названия совпадают. Музыка не скачивается и не становится нативно воспроизводимой без разрешённого загрузочного источника.

## Уведомление по расписанию

Готов безопасный отдельный CLI:
```bash
python -m music_bot.weekly_notify --send
```
Он читает приватные BOT_TOKEN, OWNER_TELEGRAM_ID и MUSIC_DB_PATH из окружения, запрашивает дайджест и присылает его **только владельцу**. После подтверждённого ответа Telegram записывает receipt по ISO-неделе: повторный запуск в ту же неделю не спамит. При ошибке доставки отметка не ставится, возможен повтор. Конкурирующие запуски блокируются lease с TTL. После неоднозначного сетевого таймаута Telegram возможно повторное сообщение — абсолютной exactly-once гарантии нет.

**Расписание намеренно не создано**: бот не развёрнут, Soodoo production не освобождён. Когда появится отдельный сервер music, пользователь сможет самостоятельно добавить задание cron или systemd timer один раз в неделю, выполняющее команду из контейнера music. Без явного `--send` CLI ничего не отправляет. Не нужно передавать секреты в GitHub.

ListenBrainz: https://listenbrainz.readthedocs.io/en/latest/users/api/index.html
