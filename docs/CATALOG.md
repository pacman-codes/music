# MusicBrainz + ListenBrainz: metadata-only поиск

Этап v0.4: код есть в GitHub, но реальное сетевое взаимодействие на продакшен-сервере и на телефоне **не тестировалось**.

## Что реально работает в коде

- MusicBrainz `GET https://musicbrainz.org/ws/2/recording/?query=...&fmt=json`.
  Возвращает оригинальное название, артиста, duration, MusicBrainz recording MBID.
- Схлопывание повторных записей по нормализованным `(artist, title)`, опциональное скрытие live/remix/cover-версий.
- MusicBrainz `GET /ws/2/artist/?query=artist:"Имя"&fmt=json` для выбора seed Artist MBID.
- ListenBrainz `GET https://api.listenbrainz.org/1/lb-radio/artist/<mbid>` с режимами `easy/medium/hard`. Отдаёт recording MBID по похожим артистам.
- Батч-поиск recording MBIDs через MusicBrainz (`rid:<uuid> OR rid:<uuid>`), затем удаление дубликатов и версий.
- Одна серверная SQLite-база хранит кеш ответов внешних каталогов и список `📌 Отложено`.
- Отложить можно только запись с MBID, которую сервер ранее получил от каталога; нельзя произвольным запросом подсунуть URL или аудио.
- API защищён Telegram `initData` и `OWNER_TELEGRAM_ID`. Только авторизованный владелец может делать внешние запросы.
- Frontend показывает отдельную пометку «Пока без аудио» и различает локальную библиотеку и внешний каталог.

## Важные ограничения

MusicBrainz и ListenBrainz — каталоги **метаданных**, а не коллекции готовых аудиофайлов.
Найденная запись не будет воспроизводиться родным плеером Telegram без реальной загрузки в него.
Автоматическое скачивание с YouTube пока не реализовано. Есть отдельный ограниченный импорт прямых MP3/M4A с вручную разрешённых HTTPS-доменов (см. `docs/IMPORT.md`). Нет обещаний обхода DRM, лицензий и условий сайтов.
Название «Радио» в новой секции означает **подборку возможных новых записей**, а не потоковый плеер. Обычная локальная /wave продолжает отправлять загруженные файлы.

## Ограничения API и защита

- Указан непустой User-Agent с URL проекта; для публичного MusicBrainz действует ограничение 1 запрос/сек на IP. Код резервирует слоты в **общей SQLite-базе** для bot + web процессов с интервалом 1,1 с. На разных машинах за одним внешним IP потребуется отдельный общий ограничитель.
- Кеш SQLite на 24 часа (поиск/радио) и до 7 дней для стабильных ID. Результаты не содержат токенов.
- Только фиксированные HTTPS-хосты `musicbrainz.org` и `api.listenbrainz.org`. Внешние редиректы не принимаются.
- Таймаут до 8 секунд, отказ от ответов более 1 МБ, санитизация поискового запроса и валидация MBID.
- Временная недоступность внешнего API возвращает ошибку, но не ломает локальную медиатеку.

## Подтверждённые совпадения и радио по песне

Когда в библиотеке есть аудиофайл, совпадение его названия с MusicBrainz-записью **само по себе не доказывает идентичность**. Теперь каталог возвращает:
- `local_track_id` — только для реально загруженного и подтверждённо связанного аудио;
- `possible_match_track_id` — приблизительное совпадение по названию и артисту, требующее явного подтверждения;
- `match_confirmed` — было ли подтверждение (или загрузка связанного файла).

В Mini App можно нажать «🔍 Найти запись», выбрать точный оригинал и подтвердить связь. В чате команды `/identify ТРЕК_ID` и `/unmatch ТРЕК_ID`. Импортированные связи нельзя перебить ручной правкой, чтобы не сломать повторный импорт.

`/radiotrack ТРЕК_ID` или «🎸 Радио» в Mini App обращается к ListenBrainz с подтверждённым Artist MBID, если он известен, или по названию исполнителя, если нет. Результат — **только новый каталожный список**, а не самопроизвольно добавленные треки.

## Персональные открытия

`/recommend` и кнопка «✨ Для меня» в Mini App используют до трёх наиболее подходящих любимых артистов. Оценка 1–10, явный лайк и ручные отметки скипов/дослушиваний влияют на выбор образцов. Песни с оценкой <=4, явным дизлайком или частыми ручными пропусками не становятся положительными образцами. Результаты разных артистов перемежаются и дедуплицируются; уже имеющиеся в библиотеке исключаются по проверенному MBID и нормализованному имени.

Если Spotify-like «Волна» ещё не имеет аудиофайла, она не может проиграть его в родном Telegram-плеере. Новая персональная секция предлагает записи для будущего импорта, не подменяя их фиктивным аудиоплеером.

## Переход из каталога к YouTube (ручной выбор)

При включённом YouTube-поиске новая кнопка «▶ Найти на YouTube» или команда `/ytfor MBID` предлагает несколько роликов по названию, артисту и длительности. Возвращается **эвристическая оценка совпадения**, а не подтверждение идентичности и не аудиофайл. Live/remix и различия длительности помечаются предупреждениями. Даже высокий балл не запускает загрузку автоматически; владелец вручную выбирает вариант и должен иметь право на скачивание.

## Следующие шаги

1. Проверка реального MusicBrainz/LB-ответа на работающем сервере, обработка 429/503, длительных запросов.
2. Подтверждение идентичности локального трека и MBID человеком (текстовое совпадение не является доказательством).
3. Импорт из источников, где разрешено получение файла; сохранение Telegram `file_id`.
4. Смешивание местных любимых записей с новой музыкой по схеме 60/30/10, **только если файлы доступны**.
5. Элементы «меньше такого» и отдельные оценки для новых кандидатов.

## Обычный Telegram-бот без Mini App

- `/find Portishead Roads` — найти записи MusicBrainz и показать кнопки «📌 Отложить».
- `/radio Portishead` — похожие записи ListenBrainz. Если исполнитель не указан, используется первый подходящий из любимой библиотеки.
- `/saved` — список отложенных записей, кнопки удаления.
- `/identify 12` — выбрать точную запись для уже имеющегося файла.
- `/unmatch 12` — убрать ошибочную ручную связь.
- `/radiotrack 12` — поиск новых записей от конкретного трека.
- `/recommend` — персональная подборка по высоким оценкам и избранному.

Эти команды работают на aiogram long polling и **не требуют HTTPS для Mini App**, но требуют сервер с исходящим HTTPS к каталогам. Найденные метаданные не равны аудиофайлу.

## Сразу слушать найденную запись

В чате `/find` и `/saved` показывают кнопку «▶ Слушать» для **подтверждённой** MBID→Telegram file_id связи; Mini App — такую же кнопку прямо в карточке. Совпадение названия без подтверждения не предоставляет кнопку аудио. Один MBID не связывается с двумя разными файлами, чтобы не отправить ошибочную версию; для исправления ручного соответствия сначала отвяжи её (`/unmatch ID`).
