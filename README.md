# music

Личный музыкальный Telegram-бот с собственными плейлистами, «Волной» и первой версией Mini App. **Главный плеер — нативный Telegram.** Репозиторий полностью заменил старое дерево VOID в ветке main; история прежних коммитов осталась.

## Реализовано в GitHub

- Владелец-only Telegram-бот (aiogram), библиотека на SQLite.
- Приём аудиофайлов, Telegram file_id, «Мне нравится», собственные плейлисты и поиск.
- Переименование, удаление, добавление и изменение порядка песен в плейлисте.
- Локальная «Волна»: независимые оценки 1–10, любимые песни, учёт вручную отмеченных скипов/дослушиваний, штраф за повторы.
- **Динамическая «Волна»:** каждые следующие 10 треков генерируются с учётом самых свежих оценок/ручных отметок. Воспроизведение через нативный Telegram-плеер; продолжение кнопкой «Ещё 10».
- Одна панель оценок каждого трека порции, история отправленных треков. Обычные плейлисты сохраняют свой фиксированный порядок.
- Mini App: библиотека, поиск, оценка 1–10, ручные кнопки «Пропустил»/«Дослушал», плейлисты и отправка музыки в чат.
- **Новая музыка:** поиск записей MusicBrainz, радио похожих исполнителей ListenBrainz и отдельный список «📌 Отложено». Внешние результаты — метаданные, не аудиофайлы.
- Доступ к музыкальному каталогу **без Mini App**: команды `/find`, `/radio`, `/saved` и обычные кнопки Telegram для добавления находок в отложенное.
- **Совпадения MusicBrainz:** ручное подтверждение MBID для уже загруженной песни, раздельные статусы «возможно совпадает» и «подтверждено»; радио по отдельному треку с точным Artist MBID при наличии.
- **✨ Для меня:** многосоставная подборка от ListenBrainz на основе до трёх любимых/высоко оценённых артистов, с фильтрацией низких оценок, ручных частых пропусков и песен из локальной библиотеки.
- **Опциональный импорт:** прямой MP3/M4A с заранее разрешённого HTTPS-хоста, временное хранение до 45 МБ, отправка `sendAudio`, привязка настоящего Telegram `file_id` к MusicBrainz MBID. По умолчанию выключен.
- **YouTube (opt-in):** поиск без ключа API через `yt-dlp`, импорт аудио по найденному VIDEO_ID с конвертацией FFmpeg в MP3 и отправкой в нативный Telegram-плеер. Ограничения: видео до 20 минут, временный диск до 80 МБ, итоговый файл до 45 МБ и таймаут 120 секунд. Два независимых выключателя для поиска и скачивания, оба по умолчанию выключены.
- Ограничение запросов MusicBrainz (не чаще одного обращения за 1,1 секунды **на общую SQLite-базу bot + web**), кеш SQLite, запрет произвольных URL/редиректов и лимиты размера ответа.
- Backend проверяет подпись Telegram initData, временную метку и ID владельца.
- Контейнеры bot и web, GitHub CI, автоматические тесты.

**Ещё нет:** автоматического нахождения доступного аудиофайла по записи MusicBrainz, надёжного связывания поиска YouTube с MusicBrainz, полноценного смешивания новых файлов в «Волну», просмотра фильмов/аниме и готового публичного HTTPS. **YouTube-импорт написан, но не проверен на реальном YouTube или телефоне**, а сам сервис может ограничивать извлечение аудио. Прямая загрузка разрешённых MP3/M4A по ссылке — отдельная, отключённая по умолчанию функция. Mini App/плеер пока не проверяли с настоящего телефона.

## Быстрый запуск локально

Python 3.12+; запускать только с собственным токеном от BotFather.

1. `python -m pip install -e ".[dev]"`
2. `cp .env.example .env` — задать BOT_TOKEN и OWNER_TELEGRAM_ID.
3. `python -m music_bot.main` — бот (long polling).
4. `uvicorn music_bot.api:create_app --factory --host 127.0.0.1 --port 8085` — локальный backend Mini App.

Или `docker compose up -d --build`. Для YouTube-пакета (yt-dlp + FFmpeg) в локальном `.env` поставить `MUSIC_WITH_YOUTUBE=true` и нужные `MUSIC_ENABLE_YOUTUBE_SEARCH`, `MUSIC_ENABLE_YOUTUBE_DOWNLOAD`, затем пересобрать. По умолчанию образ остаётся лёгким, а поиск и скачивание отключены. В Compose web доступен только на 127.0.0.1:8085. Для Telegram Mini App **обязателен реальный HTTPS адрес** и WEBAPP_URL в .env; прямой HTTP localhost на телефоне не подходит. До настройки адреса бот работает без веб-кнопки, через обычные команды.

Локальные данные SQLite: путь MUSIC_DB_PATH (по умолчанию data/music.db); в Docker — volume music_data. Не удаляй volume при обновлении.

Ручной согласованный backup: `python -m music_bot.backup --database data/music.db --output backups`. Скопируй созданный sqlite3-файл **за пределы сервера**, иначе при его потере бэкап тоже пропадёт. Для контейнеров путь базы — /app/data/music.db.

## Команды

/start, /library, /search текст, /liked, /like ID, /unlike ID, /dislike ID,
/rate ТРЕК_ID 1-10, /skip ТРЕК_ID, /finished ТРЕК_ID,
/find Песня /radio Исполнитель /radiotrack ТРЕК_ID /recommend /saved,
/identify ТРЕК_ID /unmatch ТРЕК_ID,
/import MBID https://разрешённый-хост/track.mp3,
/yt Название /ytget VIDEO_ID (по умолчанию выключены),
/playliked, /newplaylist Название, /playlists, /playlist ID,
/renameplaylist ID Название, /deleteplaylist ID,
/addto ПЛ_ID ТРЕК_ID, /removefrom ПЛ_ID ТРЕК_ID, /move ПЛ_ID ТРЕК_ID ПОЗИЦИЯ,
/playplaylist ID, /wave, /discover.

Кнопки в Telegram позволяют обойтись без большей части этих команд.

Telegram не предоставляет боту события фактического прослушивания/пропуска; «Волна» обучается на ручных отметках и истории выдачи. HTML-виджет с оценкой 1–10 создан **только как прототип** и не отправляется ботом: Telegram временно блокирует отправку виджетов обычными production-ботами (issue tdlib/telegram-bot-api#947), а aiogram ещё не поддерживает 10.4. Рабочий интерфейс оценок — стандартные Telegram inline-кнопки и Mini App. Внешний URL не становится нативным аудио без реальной загрузки в Telegram.
